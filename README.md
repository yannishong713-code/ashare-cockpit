# 🎯 A股资金·政策驾驶舱

个人每日一屏：打开 30 秒看懂「今天市场状态、钱往哪走、持仓怎么办、现在是第几个赚钱阶段、下次机会/风险」。

> 手机 + 电脑均可访问。数据每天由 GitHub Actions 自动抓取更新；也可以点按钮手动「云端更新」。

## 页面怎么看

从上到下 7 块，第一屏就能完成首次判断：

1. **今日结论** — 观望/谨慎/持有…一句话 + 上证/成交/主力/涨跌
2. **三大变量** — 经济 / 政策 / 资金 各自状态
3. **钱往哪里走** — 主力资金流入/流出 TOP3（含 5/10 日连续性）
4. **我的持仓** — 只给动作：加仓 / 逢跌加 / 持有 / 等待 / 减仓
5. **赚钱周期** — ①经济弱→②政策发力→③资金集中→④放量→⑤赚钱效应
6. **当前最大机会** — 没有强信号就显示「暂无明确主线」
7. **今日操作** — 总仓位 / 最优换仓 / 未来 3 件重要事件

判断原则（规则引擎严格执行，绝不臆造）：

- **经济弱 ≠ 卖股票**，**政策发力 ≠ 追涨**
- 存量资金阶段：**卖弱 → 买强**，禁止简单加总仓位
- 只有出现「**政策二次定价信号**」（政策加码 + 成交放量 + 资金连续流入 + 板块跑赢指数）才提示提高进攻仓位

## 数据从哪来

| 类型 | 来源 | 说明 |
| --- | --- | --- |
| 指数/ETF/涨跌家数/板块资金流 | 腾讯行情 + 东方财富 | 自动，每个卡片标注行情时间 |
| 主力资金(全A) | 东方财富个股求和 | 自动（北交所不计入，见卡片口径） |
| PMI / CPI/PPI / 社融 | **手动维护** | 每月发布后填 `data/overrides.json` |
| 政策动态 / 重要事件 | **手动维护** | 同样在 `data/overrides.json` |

每个结论都带「数据日期」；抓不到的数据一律显示 **暂无数据**，禁止编造。

## 怎么改持仓 / 宏观

所有可维护项都在 **`data/overrides.json`**（带中文注释）：

- 加/删持仓：编辑 `holdings` 列表（code 用 `sh`/`sz` 前缀 + 6 位代码）
- 宏观数据：`macro.items`（带发布日期与来源）
- 政策与事件：`policy` / `events`（带日期与来源）
- 强改当日结论：`manual` 里填了即覆盖自动判断

> 改完推送即可，GitHub Actions 会用它重新计算数据。也可以直接在 GitHub 网页里编辑后提交，无需本机。

## 手动云端更新

自动任务每天约 15:25（北京时间）抓取一次收盘数据。
随时手动刷新：打开仓库 → **Actions** → **refresh-data** → **Run workflow** → 等 1 分钟页面即有新数据。

## 本地跑（可选）

```bash
pip install requests
python scripts/update.py            # 抓最新行情 + 重新判断
python scripts/update.py --no-fetch # 只重算判断（用 tmp/raw.json）
```
